# Pump.fun Paper Sprint Bot

A momentum sniper for the make.fun Pump.fun Paper Sprint: it buys each fresh pump.fun coin once (0.15 SOL) as soon as the size cap allows, then exits on take-profit (1.8x entry), stop-loss (0.65x entry), a trailing stop (peak 1.10x, sell at 0.85x peak), or a 1500-slot time exit. Fast turnover across many coins is how it reaches the 20-distinct-mint breadth guardrail. Fully deterministic — bigint price comparisons only, no clock, no randomness.
